# Customer Assistant

The Customer Assistant is a read-only, Customer-scoped harness. It retrieves only approved `customer_rag` chunks, combines them with live menu/order read facts, and records a bounded conversation for the authenticated customer. Anonymous requests receive public content only. The versioned `prompt.md` is loaded and its SHA-256 is recorded with authenticated requests. Prompt Guard is Customer-input-only; `off`, `clear`, `blocked`, and `unavailable` outcomes are logged, and classifier outages or rate limits fail open. No mutation tools are exposed. The 60-case DDR-90 draft evaluation is persisted as a DRAFT result until the CA approves it in-app.
